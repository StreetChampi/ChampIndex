# Illustrations Champi

Dépose ici les illustrations originales de l'identité visuelle de Champi.

## Conventions
- Privilégier le **SVG** pour les formes, silhouettes et pictogrammes.
- Utiliser le **PNG transparent** uniquement si le dessin nécessite une texture raster.
- Garder des noms simples, sans espaces ni accents.
- Pour chaque fichier, préciser son rôle dans le nom ou dans la liste de livraison.
- Ne pas intégrer de texte dans les illustrations : les textes de l'interface seront gérés par le code.

## Fichiers souhaités
Voir la liste préparée dans la conversation avant de produire les visuels. Les fichiers peuvent être ajoutés progressivement.
